# AI Opportunity Generator

AI-powered CRM opportunity generation prototype built using Streamlit and OpenAI.

## Features

- AI-generated opportunity details
- AI-generated solution bundle
- Voice-to-text customer requirements
- Opportunity CRUD operations
- Persistent opportunity storage
- Streamlit UI

## Tech Stack

- Python
- Streamlit
- OpenAI API

## Run Locally

```bash
streamlit run app.py
